日期：2026-11-09　基线：0.4.74 发布版（源码包 sha256 `4666a170…c4bfc5`）
规则：**一步一版、一步一长跑、一步一回滚开关。** 上一步没过 04 验收，不开下一步。
v1 → v2：每项改动写明 **文件 + 函数 / 回滚方式 / 长跑验证项**；新增步 2（看门狗分级）；顺序按 0.4.74 长跑结论重排。

## 0. 开工规则（历史教训）

| 教训 | 规则 |
|---|---|
| 测的是旧二进制 / 旧源码包 | 验收前截图设置页三项版本号；交给审查者的源码包附 sha256 与关键文件字节数清单 |
| 拿旧报告当现状 | 文档与注释引用行号必须带版本号 |
| 指标归零被当修好 | 负向指标必须配正向指标（`sent` 在涨、对端 `inRtp` 在涨、`node=true`） |
| 断言写中间量 | 断言写咔哒次数、RTP 间隔、回传电平 |
| `-1` 当真实值 | 测量失败记 `null`，单独计数 |
| try/catch 吞错 | 禁止空 catch，至少写一条 `event:error` |
| UI 说成功、链路没建 | 档位、开关状态从 native 读回 |
| **短测当验收（0.4.73→0.4.74）** | 动音频的改动最少中测 4 分钟，涉及守护/看门狗的最少长测 30 分钟 |
| **自愈制造故障** | 任何自愈动作必须有级别、冷却、日志，且不得重建主降噪链 |

## 1. 模块职责

| 模块 | 文件 / 对象 | 职责 | 不负责 |
|---|---|---|---|
| 采集调度 | denoise-worklet.js `FongDenoiseProcessor.process` | 128↔480 缓冲、饥饿兜底、延迟调速 | DSP |
| 处理调度 | denoise-worker.js `step` / `takeFar` / `applyCommands` | 取块、调 native、far 对齐、统计 | UI |
| DSP | rust/native `set_mode` 等；rust/dsp | AEC、降噪四档、啸叫、瞬态 | 线程调度 |
| 参考链 | renderer.js `AecRef`（`sync` / `syncCapStreams` / `resync` / `watch`） | far 参考挂载与看门狗 | 主降噪链 |
| 音频编排 | renderer.js `Mic.start` / `_startDenoiseGuard` | 建链、切档、旁路守护 | DSP 细节 |
| 通话 | renderer.js `Room` | 信令、PC、重连、getStats | 音频处理 |
| 主进程 | main.js | 热键、托盘、更新、日志落盘（新增） | 音频 |
| 服务端 | server/*.go | 鉴权、空间、SFU 转发 | 音频内容 |

## 2. 改动清单（执行顺序）

### 步 1　日志与诊断导出（R6）
- **改动点：**
  - 新增 `client/diag-log.js`：`diag.tick()` 每 10 秒汇总一行（字段见 00 文档 Q7），`diag.event(name, data)`。
  - `main.js`：IPC `diag:append` 追加写 `userData/logs/fong-YYYYMMDD.jsonl`，1 MB 截断，启动删 7 天前；`diag:export` 打包 3 天。
  - `preload.js`：暴露 `diag.append` / `diag.export`。
  - `denoise-worklet.js FongDenoiseProcessor.process`：饥饿进入次数、最长饥饿时长写进新 SAB 计数槽（不在音频线程 postMessage）。
  - 埋点：`AecRef.watch`（heal）、`Mic.start`（mode_switch）、`_startDenoiseGuard`（bypass）、`Room.reconnect`、`devicechange`、`onconnectionstatechange`。
- **回滚：** 不加载 `diag-log.js`；其余代码只调用可空对象 `window.diag?.event`。
- **长跑验证：** 中测 4 分钟——日志恰好 24 行、每行正向字段非 null、文件大小 ≈ 5 KB；日测一天 ≤ 600 KB。

### 步 2　看门狗分级 + `_heals` 清零（R1a、R4）
- **改动点：**
  - `renderer.js AecRef.watch`：写指针恢复分支加 `this._heals = 0`（一行，先单独发版）。
  - 同函数：判据加"该 mid 的 `packetsReceived` 2 秒内在涨"（00 文档 Q2 表）。
  - 同函数：升级路径改为 L1 `resync` → L2 写 `C_CMD_AEC=0` 旁路 AEC → L3 只重建 `aec-ref-worklet`（新增 `AecRef.rebuildRef()`，不调用 `stop()` 里断主链的部分）；60 秒冷却；1 小时 L3 > 3 次停止自愈并提示。
  - `denoise-worker.js applyCommands`：处理 `C_CMD_AEC`；AEC 恢复时保留滤波器系数。
- **回滚：** `S.healV2=false` 回到 0.4.74 逻辑；`_heals` 清零那一行单独可 revert。
- **长跑验证：** 长测 30 分钟 ×3 轮，每轮对端闭麦/开麦 10 次、进出频道 2 次：`heal` L3 = 0；任意 10 分钟窗口 `underruns` 增量 ≤ 首 10 分钟 2 倍；日测一天：L3 = 0。

### 步 3　饥饿直通 + 调速器 + far 1:1（R1b、R4）—— PR #1，已基于 0.4.74 发布版重做
- **改动点：**
  - `denoise-worklet.js FongDenoiseProcessor.process`：饥饿时 2 ms（96 样本）从最后处理样本淡到原始输入，数据回来 2 ms 淡回；水位 > prefill+2 且当前块 < -50 dBFS 跳一块、> prefill+5 无条件跳，接缝 2 ms 交叉淡化；诊断槽仅 `diag` 开时读。
  - `denoise-worker.js step`：`MAXLAG` 3→6；新增 `skipFar(n)`，near 丢几块 far 丢几块。
  - `denoise-worker.js takeFar`：积压钉在 2 块，> 6 重同步；新增 `farLag`、`farResyncs`。
- **回滚：** revert 两个文件；若只是延迟变大，单独把 `MAXLAG` 改回 3（仿真：咔哒仍为 0，最大延迟回到 37 ms）。
- **长跑验证：** 离线仿真 10 分钟（已做：0.4.74 发布版 94 次 → 0 次）；真机长测 30 分钟 + cs2：咔哒 ≤ 2、单次饥饿 ≤ 100 ms 占比 ≥ 95%、`farLag` 在 1–3。
- **注意：** Q3 的例外（外放 + 饥饿 > 100 ms 改淡到静音）作为参数 `STARVE_PASS_MAX_MS` 一并加入。

### 步 4　Opus 默认值（R3）
- **改动点：** `renderer.js` 顶部 `OPUS_TIERS` 改为 `[32,48,64,96,128]`、`OPUS_MAX` 改 128、默认 48；SDP 改写函数（926 行 `want`）`cbr:'0'`、ptime 20；设置页加"音乐模式"恢复 256k CBR。设置迁移只在首次升级执行一次并记 `event:settings_migrate`。
- **回滚：** 常量改回。
- **长跑验证：** 中测 10 分钟弱网（clumsy 丢包 3%、±30 ms）：新旧各一轮，`concealedPct` 新 ≤ 2% 且 ≤ 旧。

### 步 5　切档热切（R2）
- **改动点：**
  - `renderer.js` 档位按钮回调：只调 `window.Denoise.setMode(m)`，不调 `Mic.start()`；随后显式 `_startDenoiseGuard()`；UI 档位读 native `get_mode()`。
  - `_startDenoiseGuard`：删掉"依赖 Mic.start 重建"的前提注释，改为显式入口。
  - `rust/native set_mode`：预热一块 → 新旧并行一块、480 样本等功率交叉淡化 → 释放旧引擎；低延迟档加延迟线对齐 544 样本。
- **回滚：** `S.hotSwitch=false` 回到重建路径；native 保留旧 `set_mode` 行为作 `set_mode_hard`。
- **长跑验证：** 中测 4 分钟内切 20 次：咔哒 0、RTP 间隔 ≤ 60 ms；之后接着长测 30 分钟不切档，确认守护基线未被破坏（`bypass` 0%）。

### 步 6　CPU 守护 → 16k 分带（R5）
- **改动点：**
  - `denoise-worker.js step`：记 `native.process` 耗时，2 秒滑窗，均值 > 7 ms 或 p99 > 9 ms 写 `C_REQ_DOWNGRADE`；`dropped` 按 1 秒增速（> 5 块/秒持续 3 秒）接入同一守护。
  - `renderer.js _startDenoiseGuard`：收到降档请求切低占用档并提示。
  - `rust/native`：专用推理线程 + `AvSetMmThreadCharacteristicsW("Pro Audio")`；`rust/dsp/src/gtcrn48.rs run_onnx` 改 IoBinding，去掉每帧约 80 次小分配；新增 16k 分带路径。
- **回滚：** `S.autoDowngrade=false`；档位映射回 48k 模型；线程开关回到 worker 同步调用。
- **长跑验证：** 低配机长测 30 分钟（后 10 分钟开游戏）：p99 ≤ 7 ms 或 2 秒内出现降档事件；R1b 同样成立。

### 步 7　基础功能（R7–R12）
- **先拆再加：** `renderer.js` 拆为 `audio/`（AecRef、Mic、守护）、`call/`（Room、重连、统计）、`ui/`。拆分单独一版，行为零变化，用回归清单 + 长测 30 分钟验收。
- 再加：试听（R8）、信号格（R9）、重连提示（R10）、TURN（R11，服务端 pion/turn 监听 TCP 443，与 SFU 同进程）、版本显示（R12）。
- **回滚：** 每项一个开关。
- **长跑验证：** 回归清单 + 长测 30 分钟（确保拆分没动到音频时序）。

## 3. 风险登记

| 风险 | 触发 | 缓解 |
|---|---|---|
| `_heals` 清零后 L1 无限重试 | 参考真的断了 | L2/L3 分级 + 冷却 + 每小时上限 |
| 调速器切掉字头 | 起音时水位高 | 只在安静块跳；硬跳需 prefill+5 |
| 外放时饥饿直通带回声 | 对端外放 + 抢核 | `STARVE_PASS_MAX_MS=100` |
| Opus 迁移影响放歌的人 | 音乐场景 | 音乐模式开关 |
| 热切漏掉守护复位 | 日后改切档路径 | 显式调用 + 单测覆盖 |
| 拆分 renderer.js 引入回归 | 步 7 | 拆分单独一版，行为零变化 |
| 服务器是真正瓶颈 | steal 高 | R13 先测，必要时先换规格 |
