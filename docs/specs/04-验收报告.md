## 0. 通用规则

1. **双向判据：** 负向（underruns、dropped、backlog、bypass）必须配正向（`sent` 每 10 秒 ≥ 900、`node=true`、`ctrl=true`、对端 `inRtp` 持续增长、对端 `recvRMS` > 0.01）。正向不成立，判"无效"，不是"通过"。
2. **两端都采：** 本地 `longrun.mjs`（underruns / jitter 曲线）＋ 对端 `real_audio_quality.mjs`（inRTP / recvRMS / 静音帧）。只有一端的数据不算验收。
3. **时长：** 短测 8 秒只证明能启动，**任何条目都不能只靠短测通过**。

| 档 | 时长 | 采样 | 用途 |
|---|---|---|---|
| 中测 | 4–10 分钟 | 每 10 秒 | 第一次周期发作（首发 1.3 分钟） |
| 长测 | 30–60 分钟 | 每 10 秒 | 多轮周期、CPU 争抢 |
| 日测 | 一天真实使用 | 日志 | 小时级累积（如 `_heals`） |

4. **版本确认：** 客户端 / native / 模型三项版本号与待验版本一致，截图进记录。
5. **测量失败记 null：** null 超过 5% 判"无效"。
6. **对照组：** 同机同场景同时长跑上一版本。
7. **基准机：** 高配一台、低配（4C4T 8 GB）一台，低配必测。

## 1. 观测字段（10 秒一行，增量值）

| 字段 | 含义 |
|---|---|
| `sent` / `underruns` / `dropped` | worker 产出块 / worklet 饥饿样本 / worker 丢块 |
| `starveEnter` / `starveMsMax` | 进入饥饿次数 / 最长一次饥饿 |
| `govSkips` / `backlogMax` / `latMs` | 调速跳块 / 输出环最大积压 / 链路延迟 |
| `procMsAvg` / `procMsP99` | native 单块耗时 |
| `farW` / `farLag` / `farResyncs` | far 写指针增量 / far 积压 / 重同步 |
| `heals`（按级别） | 看门狗动作 |
| `bypass` | 旁路占比 |
| `inRtp` / `recvRMS` / `silentFrames` | 对端收到的包 / 电平 / 静音帧 |
| `rttMs` / `lossPct` / `jbMs` / `concealedPct` | 网络与播放隐藏 |
| `clickEvents` | 相邻样本差 > 0.25 且前后 5 ms 均值 < 0.05 的次数（诊断模式） |

## 2. 逐条验收

### A1a ↔ R1a 长时间不周期劣化
- **时长：** 长测 60 分钟 ×1 + 日测 1 天。
- **步骤：** 两人通话；第 5–55 分钟间对端闭麦/开麦 10 次、第三人进出 2 次。
- **通过：** 任意 10 分钟窗口 `underruns` 增量 ≤ 首 10 分钟的 2 倍；`heals` L3 = 0；`bypass` = 0%；正向全程成立；日测 L3 = 0。
- **对照：** 0.4.74 前（看门狗 `_heals>1` 即重建）的 6 分钟曲线：1.3 m +14880、5.3 m +4800、5.8 m +2464、6.1 m +1184。

### A1b ↔ R1b CPU 争抢
- **时长：** 长测 30 分钟，后 20 分钟开 cs2（或同类游戏）。8 个 busy-loop 已证明压不出，不能代替。
- **通过：** `clickEvents` ≤ 2；`starveMsMax` ≤ 100 ms 的周期 ≥ 95%；对端录音 100 Hz 及谐波无周期峰。
- **离线预验（已做，10 分钟仿真）：** 0.4.73 循环 384 次 → 0.4.74 发布版 94 次 → 0.4.75 草案 0 次。**真机未验。**

### A2 ↔ R2 切档
- **时长：** 中测 4 分钟内切 20 次 + 随后长测 30 分钟不切。
- **通过：** `mode_switch` 耗时 ≤ 200 ms；对端 RTP 间隔 ≤ 60 ms；`clickEvents` 增量 0；无重连；UI = `get_mode()` 20/20；后 30 分钟 `bypass` 0%。

### A3 ↔ R3 弱网
- **时长：** 中测 10 分钟，新旧各一轮。
- **步骤：** clumsy 在发送端注入丢包 3%、延迟 30±30 ms、限速 2 Mbps。
- **通过：** 对端 `concealedPct` ≤ 2% 且不高于旧版；`rttMs + jbMs + latMs` ≤ 250；无重连。

### A4 ↔ R4 回声
- **时长：** 每个场景长测 30 分钟。
- **步骤：** a 双方耳机、音量 50%；b 一方外放。A 端循环播放标准语音样本，B 不说话，录 A 端回传；期间 B 闭麦/开麦 5 次。
- **通过：** a 回传 ≤ -45 dBFS；b ≤ -30 dBFS 且 2 秒内收敛；`farLag` 全程 1–3；开麦后 1 秒内回到收敛电平。

### A5 ↔ R5 低配
- **时长：** 低配机长测 30 分钟（后 10 分钟开游戏）。
- **通过：** `procMsP99` ≤ 7 ms，或超阈值后 2 秒内出现 `auto_downgrade`；客户端 CPU ≤ 15%；A1b 判据同样成立。

### A6 ↔ R6 可定位
- **时长：** 日测 1 天。
- **步骤：** 在 A1b 测试中记录三次开游戏的时刻（不告诉分析者），导出诊断。
- **通过：** 分析者只看诊断包定位三次 ±1 分钟；日志 ≤ 600 KB；导出不需开发者工具。

### A7–A12 基础功能
| 编号 | 时长 | 通过 |
|---|---|---|
| A7 热键/音量/设备 | 中测 | 游戏全屏热键 10/10；PTT ≤ 100 ms；切设备后 `node=true` 且未重建降噪链 |
| A8 试听 | 短测 ×10 | 1 秒内听到自己；关闭后 AudioNode 数回到开启前 |
| A9 信号格 | 中测 | 注入丢包 5% 后 4 秒内变色；撤销 4 秒内恢复 |
| A10 重连 | 中测 | 断网 10 秒，30 秒内互通；连续 5 次失败出提示 |
| A11 TURN | 中测 5 分钟 | 只放行 TCP 443 能通话；正常网络中继流量 < 5% |
| A12 版本 | — | 三项版本号与发版说明一致 |

### A13 ↔ R13 服务器画像
- **时长：** 一次采集 + 24 小时 `vmstat 60`。
- **通过：** 02 架构 §1.2 全部填实；`steal` p95 < 5% 且 SFU 出包间隔 p99 < 30 ms 判"服务器不是瓶颈"。

### 回归清单（每版必跑，约 10 分钟）
进频道 → 双向通话 → 闭麦/开麦 → 闭听/开听 → PTT → 调单人音量 → 切输出设备 → 切 4 档 → 退出重进 → /m/ 进同一频道互通。全过才发版。
